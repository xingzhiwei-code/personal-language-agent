# PRD-v0.4：目标驱动的学习路径（Goal → Path → Daily）

> 版本：v0.4（待确认）｜ 日期：2026-10-10
> 地位：V0 阶段内的第四次可交付迭代
> 目标读者：编码 Agent——读完直接开工，不需要再问"这个功能到底要怎么做"
> 前置阅读：`product/product-master-plan.md`（宪法与红线）、`docs/prd/prd-v0.1.md`（基线）、`docs/prd/prd-v0.2.md`（F1–F7：目标体系/相关性打分）、`docs/prd/prd-v0.3.md`（D1–D3 三段式/W1/S1）
> 背景输入：用户两轮 v0.3 真实 dogfood 反馈（2026-10-10）——"每日推荐不够智能；没有短期场景目标时应按大目标一步步推荐；单词与单词之间关联性不高，学的有点懵"

---

## 1. 背景与目标

v0.3 的 scheduler 把"大目标"（如雅思7分）只当**词库标签**用：推荐理由只回答"词从哪来"（"这10个词来自你的雅思词库"），不回答"为什么是今天、为什么是这几个"。用户真实体感：

1. **推荐没有"路径感"**：每天推的是一组孤立的点，看不到自己在通往大目标的哪一步；无短期场景目标时尤其明显——没有场景加权托底，就只剩裸的词频/标签推荐。
2. **词与词之间没有语义钩子**：孤立的词 = 孤立的记忆点。热身卡虽有 `source_span` 原句，但 10 个词分属 10 个主题时，原句救不了"懵"的感觉。

**目标**：让每一次每日推荐都能回答"为什么是今天这几个"；让学习沿着一条看得见、可验证的路径走向大目标；让每天的词自成一张网。

**非目标**：口语对话 / 发音评测仍有意缺席（留 V1）；AI 批改写作文本（留 V1）；搭配（collocation）词典（留 v0.5，见 §11）；非雅思目标类型的精细阶段模板（v0.4 只做雅思模板 + 通用模板，架构留扩展点）。

**诚实前置**（用户已确认，2026-10-10）：用户起点低于 CET-4 → 雅思 7 分，差约 2.5 个 band，正常学习强度下是 1~2 年的路。本版本**不得在任何 UI 文案中出现时间承诺**（如"X 周达到 Y 分"）；阶段推进只看数据（准出标准），不看时间。

## 2. 范围

### 做（In）

**G1 起点校准**：摸底测试（轻量）+ 用户自述并存，双信号合成起点段位；用户可手动覆盖。
**G2 阶段拆解**：大目标 → 阶段（Phase）→ 准出标准；阶段模板机制（v0.4 实装雅思模板 + 通用模板）；系统主导推进，用户可微调（跳过/回退）。
**G3 语义聚类推荐**：词关系数据（WordNet 同义/反义/词族 + 雅思话题词表，离线一次导入，运行时零 LLM）；scheduler 按"每日一主题"捞词、组内按关系排序；卡片展示关系词标签。
**G4 推荐理由升级**：启动卡一句话解释从"词从哪来"升级为"为什么是今天"（阶段定位 + 承上 + 缺口三要素，确定性拼接，缺数据不编造）。
**G5 路径可视化**：首页/目标页阶段路径条（当前高亮、完成打勾、未解锁置灰 + 本阶段准出进度 + 下一阶段预告）。
**G6 多目标切换与进度保留**：允许并存多个同级目标；主攻唯一、进度按 goalId 隔离保留、切换不删不改数据（详见 §3.6）。

### 不做（Out，留 V1 / Backlog）
- 口语对话、发音评测（延续 v0.3 非目标）
- AI 批改写作文本（延续 v0.3 非目标）
- 搭配（collocation）关系：需要搭配词典数据源，v0.4 不做，同话题共现暂作近似（见 §11）
- 系统从对话自动推断水平/自动调阶段（推断绝不能偷偷生效，沿用 v0.2 场景推断红线）
- 防断签/打卡游戏化（宪法禁止绑架式游戏化）

## 3. 功能需求

### G1 起点校准：摸底测试 + 自述水平

**入口**：新用户设目标流程中（设完大目标后引导）；老用户在目标页"重新校准起点"（不强制）。

**双信号**（用户决策，2026-10-10：两种都支持）：
1. **摸底测试**（轻量，~10 分钟）：覆盖**词汇 / 拼写 / 听辨 / 书面表达**四个可测维度（诚实口径：本系统无篇章阅读与口语评测能力，不宣称测"听说读写"），各 3–5 题，题型复用现有 `buildReviewItems` 的 recognition（词汇识别，词库按难度分级抽）/ recall（拼写回忆）/ dictation（听辨）/ writing（书面表达，看目标表达使用）。输出四科粗估 + 总段位，映射到内部统一 scale（0–9，对齐雅思 band，如 4.5/5.0/5.5…）。
2. **用户自述**：单选项（低于4级 / 4级水平 / 6级水平 / 雅思5分左右 / 雅思6分左右 / 不确定）+ 可选文字备注。

**合成规则**（确定性，权重/阈值集中配置）：
- 有摸底 → 以摸底为准，自述仅作校验：两者差异 > 1.5 band 时，UI 提示用户确认（"摸底显示约 4.5 分，你自述 6 级水平，以哪个为准？"），用户点选。
- 无摸底（跳过测试）→ 用自述，confidence 标 `low`。
- 用户可随时**手动覆盖**最终起点（宪法#2 用户最终决定权），覆盖记 `placement_completed(type=override)` 事件。

**输出**：起点 = `{ scale, value, confidence(high/medium/low), evidence: ['test'|'self_report'|'override'], updatedAt }`，遵循宪法#8（画像是假设：带 confidence / evidence / lastObservedAt）。v0.4 先做静态起点 + 手动重测；**起点随学习数据的自动校准留 v0.5**（本次诚实标注"静态起点"，不假装自适应）。

**红线**：摸底 session **不计入连续天数、不影响 mastery**——它是测量，不是学习（诚实口径，结算页/历史中明确标注"水平摸底"）。

### G2 阶段拆解：Goal → Phase → 准出

**数据模型**：`goal_phases` 表（见 §4）。同一时间一个 goal 只有一个 `active` phase。

**阶段模板机制**：按目标类型加载模板。v0.4 实装两套：
- `ielts` 模板：起点低于 CET-4 → 雅思 7 分，四段（编码 Agent 实现模板数据，内容见下表示例；具体准出阈值集中配置）：
  | 阶段 | 名称 | 内容 | 准出标准（示例，确定性口径） |
  |------|------|------|------------------------------|
  | P1 | 基础重建 | 4级核心词 3000→4500，基础语法 | 阶段词掌握度 ≥80% 且 摸底复测 ≥4级水平 |
  | P2 | 5.5~6 分段 | 学术话题词入门，四科能力起步 | 话题词掌握度 ≥75% 且 各科小测正确率 ≥60% |
  | P3 | 6.5 分段 | 高频学术搭配/长难句，写作 Task 2 分话题推进 | 写作分话题正确率 ≥70% 且 听力/阅读小测 ≥65% |
  | P4 | 7 分冲刺 | 模考节奏训练，查漏补缺 | 完整模考 ≥6.5 且 薄弱项回测达标 |
- `general` 模板（非雅思目标 fallback）：基础 → 进阶 → 运用三段，准出标准简化为"阶段词掌握度 ≥80%"。

每阶段字段：`name, description, topicSequence（话题排期 JSON，如 ['education','technology','environment','health']，供 G3 用）, entryCriteria, exitCriteria（JSON，确定性可计算）, status`。

**推进规则**（用户决策：系统为主、用户可微调）：
- 达准出条件 → 首页/目标页提示"可进入下一阶段"，**用户点确认后切换**（记 `phase_completed` + `phase_started` 事件）；用户也可选择"再巩固一阵"，不强制。
- 目标页支持手动"跳过本阶段" / "回退上一阶段"：**二次确认** + 记 `phase_override` 事件；手动操作不删除任何已学数据与事件。

### G3 语义聚类推荐

**词关系数据**（用户决策 3A：现成数据源，离线一次导入，运行时零 LLM）：
- 来源 1 — **话题标签**：雅思标准话题词表（教育/科技/环境/健康/工作/旅游等，编码 Agent 找公开词表并在 PR 附来源标注）。离线打标到词库条目；**未命中词表的不硬标**（无标签的词不参与主题聚类，走原有 relevance 逻辑，诚实 fallback）。
- 来源 2 — **WordNet**：同义（synonym）/ 反义（antonym）/ 词族（word_family，如 educate/education/educational，取 WordNet 派生关系）。
- v0.4 关系类型：`topic | synonym | antonym | word_family`。**搭配（collocation）不做**（需搭配词典，留 v0.5；同话题共现暂作近似，见 §11）。
- 存储：`word_relations` 表（`wordLemma, relatedLemma, relationType, topic?, source(wordnet|topic_list)`），`ai_generated=false`；离线导入脚本放 `scripts/`（如 `import-word-relations.ts`），幂等、可重跑。

**Scheduler 改动**（`candidates.ts` 加权处改，`scoring.ts` 复用禁重写）：
- **每日一主题**：取 active phase 的 `topicSequence` 按**学习日**（第 N 次完成 daily session，不按自然日；断更回来从上次的下一个主题继续）轮转（如第1个学习日教育、第2个科技）；**复习词不受主题约束**（due/低 mastery 优先，主题只约束新词）。
- 新词捞取：在当日主题下按现有 relevance 打分（w1 词库绑定 + w2 标签匹配，v0.2 既有权重）捞取；主题词不足 → fallback 到原有逻辑，**启动卡/推荐理由必须诚实标注**（如"今日教育话题词不足，按通用推荐补齐 N 个"，文案编码 Agent 定，不得编造）。
- **"换一批"语义**：主题约束下，"换一批" = 在**同一主题内**换一批新词；主题词不足时走上述 fallback + 诚实标注。
- **组内排序**：核心词 → 其同义/反义/词族 → 同话题其他词；学习/热身卡片角落展示 1–2 个关系词标签（如"↔ 反义：X" / "同族：Y"），**只读曝光，不计分、不增加测试量**。

### G4 推荐理由升级：从"词从哪来"到"为什么是今天"

启动卡一句话解释模板（**确定性字符串拼接**，非 LLM 生成）：

> `[阶段定位] · [承上] · [缺口]`
> 示例："雅思备考 · 第2阶段（5.5~6分）· 本周话题：教育｜昨天学了 curriculum（掌握度 60%），今天学它的同义 syllabus + 同话题 enroll；你写作教育类话题正确率 55%，这组词先补这块"

- 数据来源：phase（G2）、昨日条目 + mastery（现有）、技能/话题正确率（现有 learningTargets/学习事件）。
- **话题归因链路**（G4 的数据前提）：scheduler 生成条目（尤其 writing / dictation）时，必须把条目的 `topic` 写进条目上下文（session item 或事件 payload，编码 Agent 定实现）；G4 的"缺口"子句（如"写作教育类话题正确率 55%"）按 topic 聚合学习事件计算。无 topic 的条目不参与话题聚合，不硬归因。
- **红线**：缺哪块数据就不说哪块（如无昨日数据则不提"昨天"）；无阶段信息（老用户未校准）时 fallback 到 v0.3 文案（"来自你的雅思词库"/"按词频挑的通用词"），不得编造阶段。

### G5 路径可视化

- **位置**：首页启动卡上方（信息要素见下；具体布局编码 Agent 定）。
- **要素**：阶段节点条（P1→P2→P3→P4：当前高亮、完成打勾、未解锁置灰）+ 本阶段准出进度（如"阶段词掌握度 62%（准出 80%）"、"摸底复测：未完成"逐项列出）+ 下一阶段一句话预告。
- **气质**：信息展示，不是游戏化；**禁止**"差 X 天掉段""再学 N 天解锁"类焦虑文案（宪法#10：Agent 是助手不是监工）。

### G6 多目标切换与进度保留

**业务判断**（2026-10-10，用户提问、yiyi 拍板）：允许多个同级目标并存、切换着学。不允许的代价更大（真实多线程学习需求；宪法#2 用户最终决定权）。但必须用规则护住主线，不能裸奔。

**三条规则**：
1. **主攻唯一**：同时只能有一个 primary（v0.2 F7 已有 `goals_one_primary_uidx` 约束）。每日新词、阶段路径、推荐理由全部围绕主攻；次要目标进入"保温"状态——不产生新词推荐，但所有数据原样保留。
2. **进度按 goalId 隔离，切换只是换镜头**：
   - 天然按目标存的：`goal_phases`、`learningTargets`、`scenarios`、`wordlists.goalId`——切换时原样冻结，切回即恢复。
   - 全局存的：`learner_states.mastery` 按 (learner, subject) 存，与目标无关；"目标进度" = 该目标词集（经 wordlist/scenario 绑定）上的掌握度聚合，**视图计算，不迁移数据**。
   - `learning_events` 本身无 goalId，经 `sessions.goalId` 归因——**要求**：所有学习 session 必须可靠写入 goalId（当前主攻），否则事件归因断裂（编码 Agent 自查现有链路，缺失则补）。
   - **红线**：切换主攻不删除、不修改任何目标的数据与事件；只改"镜头"（推荐上下文 + UI 展示）。
3. **复习跨目标，新词只给主攻**：due / 低 mastery 词不分目标，照常进入复习池（遗忘不分目标）；每日新词预算只分配给主攻，防止两头稀释。

**配套**：
- **起点是人的属性，阶段是目标的属性**：新目标创建时，起点复用 learner 当前段位（G1 输出），UI 提示"沿用当前水平 X"并给"重测"入口；阶段按新目标类型（`goal_type`）独立生成。
- **新建目标不擅自抢主攻**：创建后询问用户"设为主攻 / 先放着"，默认不切换（宪法#2）。
- **v0.4 不做**：按天/按周自动轮换目标的智能调度（"周一雅思周二商务"）——切换是用户的显式动作，系统跟随；自动排兵布阵留 V1。

**UI**：目标页"设为主攻"（v0.2 已有）保留并强化二次确认文案（"切换后今日计划将按新主攻重新生成，各目标进度完整保留"）；次要目标卡片显示"保温中 · 进度已保留"状态 + 其阶段快照（只读）。

## 4. 数据模型（需求级，实现细节由编码 Agent 定）

- `goals`：新增 `goal_type`（`ielts | general`，默认 `general`）；设目标时用户选"雅思备考"则为 `ielts`。其余字段不动。
- **老目标类型识别**（§10 迁移配套）：升级时按 `title`/`rawInput` 关键词（雅思/ielts/IELTS，不区分大小写）自动识别为 `ielts`；无法识别的，在"补做起点校准"流程中请用户确认目标类型。**不得让已有雅思目标掉进通用模板。**
- **新增 `placements`**：`id, learnerId, type(test|self_report|override), skills(JSON 四科粗估）, overallLevel(real, 内部 0–9 scale), confidence(high|medium|low), evidence(JSON), createdAt`。起点以最新一条为准。
- **新增 `goal_phases`**：`id, goalId, seq, name, description, topicSequence(JSON), entryCriteria(JSON), exitCriteria(JSON), status(locked|active|done), progressCache(JSON, 准出计算快照）, createdAt, updatedAt`。同一 goal 同时只有一个 `active`（唯一索引约束）。
- **新增 `word_relations`**：`wordLemma, relatedLemma, relationType(topic|synonym|antonym|word_family), topic?, source(wordnet|topic_list)`；`wordLemma` 建索引；离线脚本幂等导入。
- `LearningEvent` 新增类型：`placement_completed`（payload: `{ type, overallLevel, confidence }`）、`phase_started` / `phase_completed`（payload: `{ phaseId, seq }`）、`phase_override`（payload: `{ fromSeq, toSeq, direction }`）；遵循现有事件命名风格。
- **G6 无新表**：进度隔离依赖现有按 goal 存的表 + 聚合视图；唯一硬要求是 session 的 `goalId` 必须可靠写入（归因不断裂）。
- 其余复用现有 schema；命名与风格遵循现有 `schema.ts`。

## 5. UI/UX

- **目标设置流程**：设完大目标 → 引导"测一下我的起点（~10 分钟）"（可跳过 → 自述选项）；起点结果页展示段位 + confidence 诚实标注（如"摸底估算 · 置信度中"）+ "手动调整"入口。
- **目标页**：阶段列表（状态/每阶段准出条件与当前完成度/手动跳过与回退入口，需二次确认）；"重新校准起点"入口。
- **首页**：路径条（G5 要素）+ 升级后的一句话解释（G4 模板）；换一批/今日休息保留。
- **学习/热身卡片**：关系词小标签（G3，只读）。
- **气质红线**（延续 v0.3）：空状态不伪造内容；"没做完不算失败"；假设透明化（confidence/evidence 可见）；无焦虑文案。

## 6. 非功能需求

- **运行时零新增 LLM 依赖**：词关系离线一次生成；推荐理由为确定性模板拼接。宪法#4（AI Economy）遵循。
- 回归：现有全部测试全过；新增单元/集成测试覆盖：placement 合成规则（含冲突确认逻辑）、阶段准出计算、主题轮转（含 fallback 诚实性）、`phase_override` 事件、推荐理由缺数据降级。
- 性能：`word_relations` 万级查询不卡；scheduler 每日生成耗时不得显著增加（基线由编码 Agent 实测记录）。
- 浏览器兼容：无新增浏览器 API 依赖。
- Node 约束沿用 v0.3（P3）：Node 20。

## 7. 验收标准

**G1 起点校准**
1. 新用户设"雅思7分" → 被引导摸底（可跳过 → 自述"低于4级"）→ 起点落定，目标页显示如"起点：低于4级 · 摸底估算 · 置信度中"；手动覆盖后 evidence 变为 override。
2. 摸底 session 不计入连续天数、不影响 mastery；在历史中明确标注"水平摸底"。

**G2 阶段拆解**
3. 目标页显示 4 个阶段（雅思模板），当前 P1 高亮、P2–P4 置灰；每阶段列出准出条件与当前完成度（如"阶段词掌握度 62%（准出 80%）"）。
4. 构造达准出条件的数据 → 出现"可进入下一阶段"提示；用户确认后切换成功，`phase_completed`/`phase_started` 事件入库；选"再巩固"则停留，无打扰。
5. 手动"跳过本阶段" → 二次确认 → 生效且记 `phase_override`；已学数据与事件无丢失。

**G3 语义聚类**
6. 连续 3 天每日推荐：每天新词同属当日主题（如连续三天分别为教育/科技/环境话题词）；卡片可见关系词标签（同义/反义/词族至少一种出现）。
7. 主题词不足时 fallback 生效，启动卡/推荐理由有诚实标注（如"今日教育话题词不足，按通用推荐补齐 N 个"）。

**G4/G5**
8. 启动卡一句话解释含阶段定位 + 承上 + 缺口三要素；缺数据维度时对应子句缺席（如无昨日数据则无"昨天…"子句），不编造。
9. 首页路径条：阶段节点状态正确（高亮/打勾/置灰）、准出进度数字与库内数据一致、无时间承诺文案、无焦虑文案。

**G6 多目标切换**
11. 建第二个目标（如"商务英语"）→ 起点自动沿用当前段位 → 生成其独立 phases → 询问"设为主攻/先放着"；选"先放着"则原主攻一切不变。
12. 切换主攻 → 二次确认（含"各目标进度完整保留"文案）→ 今日计划按新主攻重新生成；切回原目标后，其 phases 状态/进度与切换前一致（断点续学）；全程无任何目标的数据被删除或修改；due 复习词包含非主攻目标的词。

**回归**
13. `npm run verify` 全过；Playwright 走查（v0.3 同款旅程）回归通过，无体验倒退。

## 11. 决策记录

**三个拍板决策**（2026-10-10，用户）：
1. **起点双信号**：摸底测试 + 用户自述并存；两者冲突（>1.5 band）时请用户确认；用户可随时手动覆盖（记 override 事件）。
2. **阶段系统主导、用户可微调**：达准出后系统建议、用户确认切换；用户可手动跳过/回退（二次确认 + 记 `phase_override`），数据不丢失。
3. **词关系走现成数据源**：WordNet（同义/反义/词族）+ 雅思话题词表（话题标签），离线一次导入，运行时零 LLM；未命中词表的不硬标。

**诚实 scope 决策**（2026-10-10，yiyi 建议、用户默认）：
- 低于 CET-4 → 雅思 7 分是 1~2 年的路：UI 不得出现任何时间承诺；阶段推进只看数据准出。
- 搭配（collocation）留 v0.5：v0.4 以"同话题共现"近似（同话题的词在真实语料中天然高频共现），不等搭配词典。
- 起点自动校准（随学习数据持续修正画像）留 v0.5；v0.4 为静态起点 + 手动重测，并诚实标注。

**多目标切换**（2026-10-10，用户提问、yiyi 拍板）：允许并存多同级目标、切换着学。三条规则——主攻唯一（新词/路径/推荐全围绕主攻，次要目标保温）；进度按 goalId 隔离保留（切换只换镜头，不删不改，红线）；复习跨目标、新词只给主攻。起点是人的属性（新目标复用，可重测），阶段是目标的属性（独立生成，切回断点续学）。v0.4 不做按天自动轮换，切换是用户显式动作。

**刻意不做的**：
- 摸底计入 mastery / 连续天数（它是测量不是学习，计入会污染数据）。
- 阶段自动切换（必须用户确认，宪法#2）。
- 系统从对话推断水平并偷偷调阶段（沿用 v0.2 推断红线）。
- 新建目标自动抢主攻（必须用户选择，宪法#2）。
