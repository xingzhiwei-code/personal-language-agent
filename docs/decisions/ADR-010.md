# ADR-010：v0.4 目标驱动学习路径——起点、阶段、词关系与多目标规则

- 日期：2026-10-10（用户 dogfood 反馈 → 需求讨论 → 拍板）
- 状态：已采纳
- 对应 PRD：`docs/prd/prd-v0.4.md`

## 背景

v0.3 dogfood 两轮后，用户反馈："每日推荐不够智能；没有短期场景目标时应按大目标一步步推荐；单词与单词之间关联性不高，学的有点懵。"

根因：v0.3 的 scheduler 把"大目标"（如雅思 7 分）只当**词库标签**用——推荐理由只回答"词从哪来"，不回答"为什么是今天、为什么是这几个"；词与词之间没有语义钩子。v0.4 把目标翻译成路线图：Goal → Phase → Daily。

## 决定

### 1. 起点双信号：摸底测试 + 用户自述并存（用户拍板）

- 轻量摸底（~10 分钟）+ 自述选项（低于4级/4级水平/6级水平/雅思5分左右/雅思6分左右/不确定）并存。
- 冲突（>1.5 band）时请用户确认；用户可随时手动覆盖（记 override 事件）。
- **诚实口径**：摸底只覆盖词汇/拼写/听辨/书面表达四个可测维度，不宣称测"听说读写"（系统无篇章阅读与口语评测能力）；摸底不计 mastery、不计连续天数——它是测量，不是学习。

### 2. 阶段系统主导、用户可微调（用户拍板）

- 大目标拆成阶段（如雅思模板四段：基础重建→5.5~6→6.5→7分冲刺），每段有确定性准出标准（数据口径，非时间口径）。
- 达准出后系统**建议**、用户确认切换；用户可手动跳过/回退（二次确认 + 记 `phase_override` 事件），数据不丢失。
- 被否掉的选项："阶段自动切换"——违反宪法#2（用户最终决定权）。

### 3. 词关系走现成数据源，离线一次导入（用户拍板，方案 A）

- WordNet（同义/反义/词族）+ 雅思话题词表（话题标签），离线脚本幂等导入，**运行时零新增 LLM 依赖**（宪法#4 AI Economy）。
- 未命中词表的不硬标话题标签；搭配（collocation）留 v0.5，同话题共现暂作近似。
- 被否掉的选项："大模型实时生成词关系"——灵活但贵，且可能瞎编；运行时成本不可接受。

### 4. 允许多目标并存、切换着学（用户提问，yiyi 给判断、用户认可）

- 不允许的代价更大：成年人学习本来就是多线程，工作上突然压来新目标是常态；宪法#2。
- 三条规则护住主线：**主攻唯一**（新词/路径/推荐全围绕主攻，次要目标保温）；**进度按 goalId 隔离保留**（切换只换镜头，不删不改——红线）；**复习跨目标、新词只给主攻**（遗忘不分目标；防两头稀释）。
- 起点是人的属性（新目标复用，可重测），阶段是目标的属性（独立生成，切回断点续学）。
- 被否掉的选项："按天自动轮换目标"——那是 V1 智能调度的事；v0.4 切换是用户显式动作。

### 5. 诚实 scope（yiyi 建议）

- 用户起点低于 CET-4 → 雅思 7 分是 1~2 年的路：**UI 不得出现任何时间承诺**；阶段推进只看数据准出。
- 起点自动校准（随学习数据持续修正画像）留 v0.5；v0.4 为静态起点 + 手动重测，并诚实标注。

## 被否掉的选项

- "摸底计入 mastery/连续天数"——测量污染学习数据。
- "系统从对话推断水平并偷偷调阶段"——沿用 v0.2 推断红线（推断绝不能偷偷生效）。
- "新建目标自动抢主攻"——违反宪法#2。
- "给阶段定时间表（如 8 周到 6 分）"——时间承诺是谎言，用数据准出代替。

## 后果

- 任何 PR 引入时间承诺文案、静默推断调阶段、或在切换主攻时删除/修改目标数据，必须引用本 ADR 重新决策，不得静默加入。
- v0.5 重新评估起点自动校准与搭配词典时，需先有 v0.4 的真实使用证据。
- `docs/decisions/README.md` 索引已同步。
