# ADR-001：产品定位——私教 Agent，不做"更好的多邻国"

- 日期：2026-09（产品定义讨论第 1 轮）
- 状态：已采纳

## 背景

立项之初需要回答：这个项目到底解决什么问题？市面上已有 Duolingo、流利说等成熟产品，直接竞争"更好用的背单词 App"是红海。

## 决定

定位为 **"英语私教 Agent"**，核心差异：**Agent 适应人的生活节奏，而不是人适应 App 的节奏**。

立论依据（第一性原理推导的成年人学英语 4 个瓶颈）：
1. 输入不够真实——App 里是"教学英语"，现实是会议连读、俚语、长难句；
2. 输出没有压力——语言是技能，不下水学不会游泳；
3. 反馈回路太长——学完三天后才用，大脑判定为不重要；
4. 没有"不得不"的真实场景。

因此产品框架是"**用英语做真实的事**"：输入真实、输出有压力、反馈即时、场景真实。Agent 的核心能力 = 理解你的真实生活场景 + 在你有空时出现 + 用真实材料教 + 逼你输出 + 即时纠正 + 记住你所有犯过的错。

## 被否掉的选项

- **做"更好的多邻国"（课程 + 游戏化 App）**：Duolingo 优化的是 DAU 而不是用户能力；"每天打卡很爽，但开口还是不行"。走这条路等于在别人的主场打仗。
- **做通用聊天机器人**：聊天只是交互方式之一，不是产品本身；纯聊天没有记忆、调度与学习闭环，留不住学习效果。

## 后果

- 产品没有"第 1 课、第 2 课"的课程结构；一切围绕 Learner Model 和 Scheduler 组织。
- 游戏化（打卡/积分/排行榜）被明确排除（见 ADR-007）。
- 北极星定为 Real-world Capability 而非 App Engagement。
