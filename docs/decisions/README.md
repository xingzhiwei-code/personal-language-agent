# docs/decisions — 架构决策记录（ADR）

本目录记录 personal-language-agent 的关键产品与架构决策。每篇 ADR 采用统一格式：**背景 → 决定 → 被否掉的选项 → 后果**。

"被否掉的选项"与决定本身同等重要：它们解释了"为什么不那么做"，是未来避免重复争论、也是开源后向贡献者讲述"设计心路"的素材。
