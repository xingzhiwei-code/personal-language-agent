# ADR-012：v0.5 M0 数据源 spike——WordNet 通过，搭配降级

- 日期：2026-10-17（M0 spike）
- 状态：已采纳
- 对应 PRD：`docs/prd/prd-v0.5.md` §3 W1/W2

## 背景

v0.5 的 W1（全量 WordNet）与 W2（搭配 collocation）都依赖外部数据源。按 PRD §3 与 ADR-011 决定，实现前必须先行 spike：确认数据 license 与可得性，license 无结论不得入库，任一不可得则降级且不阻塞 W1/W3。

## 决定

### 1. WordNet 数据：license 通过，可用

**License 结论**：WordNet 数据使用 **Princeton WordNet License**（BSD 风格，非 public domain、非 MIT）。已从 `en-wordnet@2.0.11` 包内 `LICENSE` 文件确认完整文本，核心条款：

- "Permission to use, copy, modify and distribute this software and database ... for any purpose and without fee or royalty" —— 允许任意用途（含商业）免费、无版税使用。
- 附加条件：版权声明 + license 文本 + disclaimer 必须出现在所有副本（含修改版）；不得以 Princeton University / WordNet 名称背书；版权归 Princeton。
- 本项目为个人本地离线学习 Agent，离线一次导入、运行时零 LLM，符合上述许可。

**可得性结论**：数据可得。已验证以下来源（均可获取完整 WordNet 3.1 DB）：

- `en-wordnet@2.0.11`（npm）：bundle 完整 WordNet 3.0/3.1 DB（`database/3.1/data.{adj,adv,noun,verb}` + `index.*` + `index.sense`），tarball 约 20MB；其 `license` 字段标 MIT 指包代码，底层数据为 Princeton WordNet License（README 明确指向 wordnet.princeton.edu）。
- `wordnet-db@3.1.14`（npm）：WordNet 3.1 数据包。
- 官方 `wordnet-3.1.tar.gz`：https://wordnet.princeton.edu/download

**注意**：现有 `scripts/data/wordnet-relations.json` 的 `_source` 误标 "public domain"，W1 全量导入时须纠正为 Princeton WordNet License 并随数据保留版权声明。

来源链接：
- https://wordnet.princeton.edu/license-and-commercial-use
- https://github.com/open-language/en-wordnet（已 archived，推荐 https://github.com/open-language/wordnets）
- https://www.npmjs.com/package/wordnet-db

### 2. 搭配数据源：不可得，降级

**结论**：无 license 清晰、可直接下载、覆盖通用搭配（如 make a decision / take responsibility）的公开搭配词表。按 PRD §3 W2 与 ADR-011 §3 执行**降级**——搭配不上线，沿用 v0.4「同话题共现近似 + 诚实标注」，不阻塞 W1/W3，无搭配逻辑残留。

**排除项与理由**：
- Academic Collocation List（ACL，Ackermann & Chen 2013，2469 项）：仅覆盖学术写作搭配，不含通用高频搭配；无明确可下载的授权文件（仅 EAP Foundation 网页展示）。
- Oxford Collocations Dictionary：商业授权，不可免费使用。
- 基于语料统计（BNC / COCA）自行抽取：BNC license 受限、COCA 付费/受限，且抽取工程量大，与宪法#4（AI Economy）+ 本版「离线、零新增依赖」不符。

来源链接：
- https://www.eapfoundation.com/vocab/academic/acl/
- https://www.eapfoundation.com/vocab/academic/acl/frequency/

## 被否掉的选项

- 使用 ACL 作为搭配源——license 不明确 + 仅学术搭配，不满足通用搭配需求。
- 引入商业搭配词典——违反宪法#4 与 license 红线。
- 自建语料统计抽取——BNC/COCA license 受限且成本高，与离线零依赖原则冲突。
- 静默换数据源 / 静默降级——违反 license 红线与「降级必须诚实标注」。

## 后果

- W2 跳过：本版不新增 `collocation` 关系类型，卡片无搭配标签，组内排序维持 v0.4（核心词 → 同义/反义/词族 → 同话题）。
- W1 全量导入须随数据保留 Princeton WordNet License 文本与版权声明，不得标注 public domain。
- W1 的锚点词表（`cet6-wordlist.csv` / `ielts-wordlist.csv`）需 yiyi 确认路径；仓库当前无此二文件（仅有 `data/samples/cet6-top1000-with-examples.csv` 样例）。
- `docs/decisions/README.md` 索引已同步。
