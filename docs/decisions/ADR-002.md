# ADR-002：架构原则——复用开源生态，Agent 做编排

- 日期：2026-09（产品定义讨论第 2–3 轮）
- 状态：已采纳

## 背景

"英语学习 Agent"拆开看是一堆已有成熟方案的能力：STT、TTS、SRS、发音评测、词典、阅读辅助。全部自研不现实。

## 决定

**能复用就不重写，能组合就不发明**，作为项目第一原则：

```
Agent（理解意图 / 规划任务 / 记忆状态 / 编排调用）← 你真正要写的代码
    ↓
开源能力 / 成熟服务（STT / TTS / SRS / 词典 / 阅读工具）← 直接复用
```

- SRS 直接复用 FSRS/SM-2 公开算法，数据格式兼容 Anki；
- 对话/纠错/解释直接用 LLM API，不微调、不自训模型；
- Prompt 设计与任务编排是护城河，不是底层能力。

## 被否掉的选项

- **全部自研**：每个单项都是大坑，"三年都做不完"；且自研 STT/SRS 不会比开源做得更好。
- **简单拼凑 5 个开源项目**：复用不等于拼凑。如果只是拼在一起，用户不如自己装 5 个 App。Agent 的价值在于**编排**：用户说 5 分钟 → 自动选"复习 + 1 个口语练习"；读到生词 → 自动进 SRS；总错一个音 → 下次专门练。

## 后果

- v0.1 落地时，确定性核心（Learner/Scheduler/Assessment/NLU）为纯函数、零 LLM 调用；LLM 只出现在对话与复杂解释。
- 选型时优先"能本地跑、License 允许"的方案；发音评测承认"开源不如商业"，V0 用文字纠错代替，不硬上。
